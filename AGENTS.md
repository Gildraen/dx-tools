# dx-tools

When `DX_AGENTS_HOME` is set, read `$DX_AGENTS_HOME/AGENTS.md` and follow its
shared guidance before working. Report an unreadable configured guide.
Without `DX_AGENTS_HOME`, use the project's guidance only.

This repository owns `bin/dx-mcp`, `taskfiles/base.yml`, and their tests.
Validate changes with `task validate` and `task test`.
